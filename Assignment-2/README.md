# Etsy Clone Project

A web application designed to replicate the core e-commerce features of **[Etsy](https://etsy.com)**, a global online marketplace focusing on handmade, vintage, custom, and unique items.

## 🚀 Project Overview

This project is built to demonstrate front-end UI design, catalog management, and search features inspired by the dynamic layout of the official Etsy website. It is designed to mirror a user-friendly shopping experience tailored toward discovering unique gifts and customized lifestyle products.

### Key Visual References
* **Homepage Layout:** Featuring banners like "Wonderfully whimsical finds" and product grids.
* **Product Discovery:** Categorized sections for "Personalized Men's Gifts", "Custom Engraved Compacts", and a dynamic countdown banner for "Today's big deals".
* **Footer Design:** Structured links mirroring Etsy's organizational transparency (Shop, Sell, About, Help) alongside local configurations.

## ✨ Features

- **Personalized Recommendations Grid:** Dynamically sized product cards containing pricing information, strike-through original prices for discounts, and product titles.
- **Responsive Navigation Bar:** Complete with a prominent search engine bar, categorized popovers, and interactive quick-access links (Gifts, Home Favourites, Fashion Finds, Vintage, Wedding Guide).
- **Interactive Multi-item Carousels:** Built-in navigational side arrows to smoothly cycle through catalog expansions under specific categories.
- **Comprehensive Footers:** Multi-column layout featuring app distribution store badges, operational policies, region settings, and social platform quick-links.

---

## 🛠️ Tech Stack

* **Front-end:** HTML5, CSS3 / TailwindCSS, JavaScript (ES6+)
* **Icons & Assets:** FontAwesome / Custom SVG components

## 📥 Installation & Setup

Follow these simple steps using Git Bash to get the project running locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate into the project directory:**
   ```bash
   cd etsy-clone
   ```

3. **Open the application:**
   * If you're building a vanilla project, simply open `index.html` in your favorite web browser.
   * If using a modern bundler environment (e.g., Vite/Webpack), install dependencies and start the dev server:
     ```bash
     npm install
     npm run dev
     ```
